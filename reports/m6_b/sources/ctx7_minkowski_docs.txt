### Install PyTorch with Specific CUDA Toolkit

Source: https://github.com/nvidia/minkowskiengine/blob/master/docs/issues.md

Ensure compatibility by installing the PyTorch version that matches your system's CUDA toolkit.

```bash
conda install pytorch torchvision cudatoolkit=10.1 -c pytorch
```

```bash
conda create -n py3-mink-2 python=3.7 anaconda
conda activate py3-mink-2
conda install openblas numpy
conda install pytorch torchvision cudatoolkit=10.1 -c pytorch  # Make sure to use the correct cudatoolkit version

cd /path/to/MinkowskiEngine
conda activate py3-mink-2
make clean
python setup.py install --force
```

### Install MinkowskiEngine with CUDA 11.X

Source: https://github.com/nvidia/minkowskiengine/blob/master/README.md

Standard installation procedure for CUDA 11.1 environments.

```bash
conda create -n py3-mink python=3.8
conda activate py3-mink

conda install openblas-devel -c anaconda
conda install pytorch=1.9.0 torchvision cudatoolkit=11.1 -c pytorch -c nvidia

# Install MinkowskiEngine

# Uncomment the following line to specify the cuda home. Make sure `$CUDA_HOME/nvcc --version` is 11.X
# export CUDA_HOME=/usr/local/cuda-11.1
pip install -U git+https://github.com/NVIDIA/MinkowskiEngine -v --no-deps --install-option="--blas_include_dirs=${CONDA_PREFIX}/include" --install-option="--blas=openblas"

# Or if you want local MinkowskiEngine
git clone https://github.com/NVIDIA/MinkowskiEngine.git
cd MinkowskiEngine
python setup.py install --blas_include_dirs=${CONDA_PREFIX}/include --blas=openblas
```

### Advanced Installation Options

Source: https://github.com/nvidia/minkowskiengine/wiki/Installation

Use install options to force CUDA, specify CUDA home, or configure BLAS libraries.

```bash
# export CXX=g++-7; If you have an older version of GCC.
pip install -U git+https://github.com/StanfordVL/MinkowskiEngine \
                           \ # if you want to force cuda installation
                           --install-option="--force_cuda" \
                           \ # if you want to force no cuda installation. force_cuda supercedes cpu_only
                           --install-option="--cpu_only" \
                           \ # optional when torch fails to find cuda_home.
                           --install-option="--cuda_home=<cuda_home>" \
                           \ # override to openblas, atlas, mkl, blas
                           --install-option="--blas=<blas>" \
                           \ # blas include and library path if default ones fail
                           --install-option="--blas_include_dirs=<csv>" \
                           --install-option="--blas_library_dirs=<csv>"
```

### MinkowskiEngine > Anaconda

Source: https://github.com/nvidia/minkowskiengine/blob/master/README.md

MinkowskiEngine supports CUDA 10.2 and CUDA 11.1, which are compatible with most recent versions of PyTorch. For all installation methods, it is essential to ensure that the installed PyTorch version matches the CUDA version used by the system's nvcc compiler.

--------------------------------

### Common Issues > CUDA Version mismatch

Source: https://github.com/nvidia/minkowskiengine/blob/master/docs/issues.md

Undefined symbol errors or invalid device function errors often indicate a mismatch between the CUDA version used by PyTorch and the version used to compile MinkowskiEngine. Verify your CUDA version with nvcc and ensure the PyTorch installation includes the matching cudatoolkit version.
