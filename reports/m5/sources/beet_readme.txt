B: DATA & FILE OVERVIEW

1. Data format: The dataset consists of point clouds provided in the ply format. Each ply file contains a region of 1m x 1m of the field.
File List: "train" contains the training patches

2. Data organisation: We provide predefined splits of the dataset, "train" contains the data used for training deep learning approaches, "val" contains the data used for validation of the hyper parameters of the approach and "test" contains the data used for testing the performance of the approach.

D METHODOLOGICAL INFORMATION

1. Description of methods used for collection/generation of data: The data was collected by a camera attached to a UAV

2. Methods for processing the data: The point clouds were generated by SfM techniques

3. Instrument- and/or software-specific information needed to interpret the data: The data can be parsed by many point cloud visualization and processing tools e.g. CloudCompare, Open3d

4. People involved in sample collection, processing, analysis and/or submission: Elias Marks, Jonas Bömer, Federico Magistri, Anurag Sag, Jens Behley, Cyrill Stachniss

5. Environmental/experimental conditions: The data was collected on a day with moderate wind and heat.
