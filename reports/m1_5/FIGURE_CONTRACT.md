# M1.5 Figure Contract

- Backend: existing Python / Matplotlib project workflow; no R and no generated mock data.
- Core argument: distinguish genuine historical information from architecture, time-query information and label difficulty. No panel implies an independent confirmation or a mechanism.
- Archetype: quantitative grids. Sources are the locked tasks and plant-level statistical CSVs, not selected favorable windows.
- Capacity figure: all six tasks, two endpoints, paired genuine-minus-repeat and genuine-minus-single-frame MAE with 95% independent-plant bootstrap intervals; negative is favorable to genuine history.
- Time figure: all three observation-offset tasks, same-architecture MLP conditions and neural time-only control; seed-mean plant MAE with plant intervals. Different query contracts explicitly labeled.
- Feasibility figure: plant counts and fixed-rule matching-error quantiles for 3/5/7 days; no test model performance in feasibility.
- Difficulty figure: preselected day5 task, leaf-count-derived observed stage, future visible-leaf decline and train-defined rapid-change strata. Include plant n and do not attribute errors to occlusion, senescence or cropping.
- Export: SVG and PDF with editable text, PNG 300 dpi, English figure text, source CSVs retained, no image manipulation. Approximately 180 mm figure width.
- QA: validate panel source coverage, finite estimates and bounds; retain rendered visual QA separately, never mark unavailable vision as PASS.
- Review risks: overlapping windows, shared genotype/capture cohorts, seed variance, small geometry subgroups, post-M1 test exposure, calendar task target matching error.
